# RiverBoat

Next.js frontend starter for a website: App Router, TypeScript, Tailwind CSS, and a shared layout with navigation.

## Scripts

```bash
npm run dev      # http://localhost:3000
npm run build
npm run start
npm run lint
```

## Layout

- `src/app` — routes (`page.tsx` in a folder becomes a URL)
- `src/components` — shared UI (`Header`, `Footer`, `Container`)
- `src/lib/site.ts` — site name, description, and nav links
